---
title: Plan first
summary: Explore, get the plan approved, then build it step by step.
spawn: none
---

1. **Explore** the code and the KB entries the task touches before changing anything.
2. **Plan.** Write a numbered plan: the steps, the files each touches, the risks, and the tests that prove it.
3. **Ask for approval** with a choices block:

   ```choices
   Approve the plan (Recommended)
   Change the plan
   ```

4. **Build** it one step at a time, running the relevant tests after each step. When a step turns out
   different from the plan, say so and ask before going on.
